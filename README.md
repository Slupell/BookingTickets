# Кинотеатр – фронтенд

SPA‑приложение для просмотра фильмов в прокате, списка кинотеатров, расписания сеансов и бронирования билетов.  
Пользователь может выбрать кинотеатр, посмотреть доступные сеансы и забронировать билеты после авторизации.

## Стек технологий

- React 19
- React DOM 19
- TypeScript 5
- Vite 7
- React Router DOM 7
- @tanstack/react-query 5
- React Hook Form
- Yup
- Tailwind CSS 4
- Axios

## Требования к окружению

- Node.js 18+ (рекомендуется актуальная LTS‑версия)
- npm 10+ (или pnpm/yarn — по желанию)
- Запущенный бэкенд кинотеатров по адресу `http://localhost:3022`

## Установка и запуск

# клонирование репозитория
git clone <repo-url>
cd my-react-app

# установка зависимостей
npm install

# запуск в режиме разработки
npm run dev


## Переменные окружения

В корне проекта создайте файл `.env`:

 - VITE_API_URL=`тут ваш URL или используйте тот, что был указан в ТЗ`


**VITE_API_URL** — базовый URL бэкенда, через который фронтенд запрашивает фильмы, кинотеатры, сеансы и выполняет бронирование.

## Структура проекта

Основные директории внутри `src/`:

- `assets/` — статические ресурсы (иконки, изображения и т.п.).
- `components/` — общие переиспользуемые компоненты:
  - `form/` — компоненты для работы с формами (Form, InputField и др.).
  - `image.tsx` — обёртка над `<img>` с учётом `VITE_API_URL`.
  - `mainLayout.tsx` — основной layout приложения.
  - `protectedLayout.tsx` — layout для защищённых страниц (требуют авторизации).
  - `menu.tsx` — главное меню приложения.
  - `queryProvider.tsx` — провайдер React Query.
- `constants/` — константы маршрутов (`routes.ts`) и ключей сессий (`sessions.ts`).
- `function/` — общие вспомогательные функции (`index.ts`).
- `modules/` — доменные модули приложения:
  - `movies/` — список фильмов и страница фильма.
  - `cinemas/` — список кинотеатров и их расписание.
  - `session/` — выбор конкретного сеанса.
  - `booking/` — оформление бронирования / билетов.
  - `user/` — профиль и данные пользователя.
  - `settings/` — настройки приложения (если используются).
- `services/` — служебные слои:
  - `api.ts` — конфигурация axios‑клиента и базового URL.
  - `isCheckAuth.ts` — утилита для проверки авторизации пользователя.
  - `router.tsx` — конфигурация React Router (маршруты приложения).

## Основные возможности приложения

- Просмотр фильмов, которые сейчас находятся в прокате.
- Просмотр списка доступных кинотеатров.
- Просмотр расписания сеансов по фильмам и кинотеатрам.
- Авторизация и регистрация пользователя.
- Бронирование билетов на выбранный сеанс после авторизации.

## Скрипты

В `package.json` определены следующие основные скрипты:

- `npm run dev` — запуск проекта в режиме разработки.
- `npm run build` — сборка проекта.
- `npm run preview` — предпросмотр собранного приложения.
- `npm run lint` — запуск линтера.
